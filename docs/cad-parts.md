# Printable parts (STL)

Two separate sets, in the order you build them. Each set is also one zip file.

| Set | Files | Pieces | Download | List |
|---|---|---|---|---|
| **1 · MC-1 monocopter (print first)** | 12 | 45 | [mc1-monocopter-stl.zip](../hardware/cad/mc1-monocopter-stl.zip) | [phase1-monocopter/printable-parts.md](phase1-monocopter/printable-parts.md) |
| **2 · RK-1 rocket (print second)** | 18 | 33 | [rk1-rocket-stl.zip](../hardware/cad/rk1-rocket-stl.zip) | [phase2-rocket/printable-parts.md](phase2-rocket/printable-parts.md) |

Every file is binary STL in millimetres, in print orientation. Settings, materials and tolerances: [3D printing guide](printing.md). The files are generated by `npm run cad`; the parts page is [web/parts.html](../web/parts.html).
