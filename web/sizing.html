Equations used

Monocopter

TWR = Tmax / (m g) (need ≥ 2.0)
hover throttle ≈ √(m g / Tmax) (thrust ∝ throttle², rough)
vane authority: τ = 2 Fv h

Rocket hop (no drag, constant thrust)

a = T/m − g, vb = a tb, hb = ½ a tb², hcoast = vb² / 2g
Real altitude is lower: drag, mass loss and thrust curve change it. Use OpenRocket / RASAero for flight predictions.
